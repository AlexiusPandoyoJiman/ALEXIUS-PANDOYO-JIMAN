PORTOFOLIO ALEXIUS PANDOYO JIMAN

CARA MELIHAT WEBSITE
1. Ekstrak file ZIP.
2. Buka folder portfolio_alexius.
3. Klik dua kali index.html atau buka melalui browser.

CARA MENGUBAH KONTAK
- Buka index.html menggunakan VS Code atau editor teks.
- Cari EMAIL_ANDA lalu ganti dengan alamat email aktif.
- Ganti tautan LinkedIn https://www.linkedin.com/ dengan profil Anda.
- Anda dapat menambahkan tautan WhatsApp pada bagian kontak.

CARA MEMBUAT WEBSITE BISA DIAKSES ORANG LAIN
Pilihan mudah: GitHub Pages
1. Buat akun di https://github.com/ jika belum punya.
2. Buat repository baru bernama portfolio.
3. Upload index.html, style.css, dan script.js (README opsional).
4. Buka Settings > Pages.
5. Pada Build and deployment pilih Deploy from a branch, pilih branch main dan folder /(root), lalu Save.
6. Tunggu proses publikasi. GitHub akan menampilkan alamat website publik yang bisa dibagikan.

Alternatif: Netlify
1. Buka https://www.netlify.com/ dan buat akun.
2. Pilih Add new site / Deploy manually.
3. Seret folder portfolio_alexius ke area deploy.
4. Gunakan alamat situs yang diberikan Netlify untuk dibagikan.

CATATAN
- Website ini merupakan template awal dan belum dipublikasikan ke internet.
- Periksa kembali deskripsi proyek agar sesuai dengan hasil akhir yang benar-benar Anda kerjakan.
- Tambahkan email, WhatsApp, LinkedIn, foto profil, dan CV sebelum dibagikan.
